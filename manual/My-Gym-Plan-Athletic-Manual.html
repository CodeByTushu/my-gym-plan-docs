01. Core Vision & Architectural Philosophy

My GYM Plan (IronTracker) was engineered with a clear mission: to deliver an uncompromising, military-grade athletic tracker that respects athlete privacy, eliminates cloud bloat, and operates at maximum speed under any condition.

🔒 100% Offline-First

No mandatory logins, zero third-party trackers, and no cloud databases. Your training weights, PIN, and habits never leave your physical device.

⚡ Zero-Framework Speed

Built with pure Vanilla ES6+ and modern CSS3. Startup time is under 50ms with a solid 60 FPS scrolling and zero battery-draining overhead.

02. The 7-12-15 Scientific Hypertrophy Protocol

Unlike generic 3x10 workout trackers, My GYM Plan organizes resistance training around the scientifically proven 7-12-15 Protocol. This three-stage periodization targets all muscle fiber types (Type IIx, Type IIa, and Type I) in a single unified workout session.

SET 1: POWER SET

7 Heavy Reps

80–85% 1RM. Recruits high-threshold motor units, triggers mechanical tension, and stimulates raw myofibrillar strength adaptations.

SET 2: GROWTH SET

12 Moderate Reps

65–70% 1RM. Maximizes muscle hypertrophy, sarcoplasmic expansion, and time-under-tension with strict concentric/eccentric tempo control.

SET 3: BURNOUT DROP

15 Fast Reps

50% 1RM drop set. Floods tissue with blood, drives metabolite accumulation (lactate/hydrogen ions), and produces extreme cellular swelling (the pump).

03. 2-Tier Room Fitness & Calisthenics System

For athletes unable to reach a commercial gym or those building foundational functional strength, My GYM Plan features a proprietary 2-Tier Room Fitness & Calisthenics Engine.

Tier 1: Daily Essentials (Non-Negotiable)

High-frequency, low-fatigue habit anchors executed every single day. Includes 10 Standard Push-ups, 10 Hindu Baithak (Bodyweight Squats), 60s Core Plank, and Doorframe Rows. Designed to stimulate synovial joint fluid and baseline metabolic rate.

Tier 2: Weekly Calisthenics Split (48h Recovery)

Progressive bodyweight strength training split across dedicated focus days (Upper Body Push/Pull, Hollow Body Core, Lower Body Explosiveness) paired with strict 48-hour muscle recovery locks to prevent overtraining.

The 48-Hour Physiological Recovery Lock

Muscle protein synthesis (MPS) remains elevated for approximately 24 to 48 hours post-workout. If an athlete trains their chest on Monday, the app dynamically locks intensive push movements for Tuesday and surfaces active recovery cues, ensuring muscle fibers heal and grow thicker before undergoing subsequent mechanical stress.

Sunday Sacred Rest Day

On Sundays, the Room Fitness interface automatically transitions into a dedicated Active Recovery Mode. High-impact routines are disabled, replaced by guided mobility drills, hydration tracking, and nervous system restorative breathing.

07. Security, SHA-256 PIN Vault & Device Privacy

My GYM Plan implements a zero-trust, device-only security architecture. There is no remote authentication server, no cloud credential harvesting, and no third-party tracking pixels.

Goku Ultra Instinct Onboarding & PIN Vault

On initial startup, athletes complete the Goku Ultra Instinct Onboarding, setting up their profile, dietary preferences, and a 4-digit master PIN.

Client-Side Cryptographic Hashing

The athlete's PIN is never stored in plain text. It is processed using client-side SHA-256 cryptographic hashing via the native browser crypto.subtle.digest('SHA-256', ...) API. When an athlete enters their PIN to unlock their profile or authorize a hard reset, the app hashes the input and compares hashes locally. 

// SHA-256 PIN Encryption Engine (Zero Server Leakage)
async function hashAthletePin(rawPin) {
  const encoder = new TextEncoder();
  const data = encoder.encode(rawPin + "_tushu_salt_2026");
  const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  return hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
}

08. Data Governance & Backup / Restore Engine

Because My GYM Plan runs 100% offline, data governance features are engineered to ensure athletes maintain complete ownership and portability of their workout history.

1. JSON Backup Snapshot & Seamless Restore

Athletes can export their complete training life into a standardized JSON file (my-gym-plan-backup.json). This backup contains:

  • All 14 internal localStorage keys (tushu_gym_*, tushu_habits_*, tushu_room_fitness_v1).
  • Workout logs, personal best weights, and custom routine modifications.
  • Habit history logs, active streaks, and completion scores.
  • Athlete onboarding profile and encrypted PIN hash.

2. 6-Month Automated Log Retention Policy

To prevent database bloat and ensure instantaneous app performance on older Android devices, the app includes an optional 6-Month Auto-Cleanup Engine. When activated, log records older than 180 days (ISO YYYY-MM-DD) are automatically pruned while preserving all-time PR records and current month metrics.

3. PIN-Protected Hard Reset (Clear Device Data)

Should an athlete wish to hand over their phone or start a brand new training phase, the "Clear Device Data" control cleanly purges all 14 local storage partitions only after confirming the athlete's SHA-256 PIN.

09. Hybrid Live Over-The-Air (OTA) Updates

The crowning engineering achievement of My GYM Plan is its Hybrid Live OTA Engine. Traditionally, Android WebView apps require distributing a new .apk file whenever a web bug is fixed or a new feature is added. My GYM Plan eliminates this friction completely.

How Live OTA Works (Under the Hood)

1. Manifest Verification: App polls https://raw.githubusercontent.com/Tushpendra-Kumar/my-gym-plan/main/ota-manifest.json.
2. Differential Check: If the remote buildNumber is greater than local build, the app surfaces an update alert.
3. Background Asset Download: Android's native Java layer downloads all modified assets into an isolated staging directory (ota_staging/).
4. Atomic Swap: Once verified, ota_staging/ is atomically swapped into active ota_www/.
5. Instant Reload: WebView refreshes to the new version in under 2 seconds. Zero APK reinstall required!
